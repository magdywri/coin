# تحدي العملات — نسخة الموقع (GitHub Pages)

## الرفع (مرة واحدة)
1. ادخل https://github.com وسجّل (مجاني) أو سجّل دخول.
2. فوق على اليمين: علامة + ثم **New repository**. الاسم: `coin` . اختار **Public**. دوس **Create repository**.
3. في صفحة الريبو الجديد دوس **uploading an existing file**. افتح الفولدر `coin-site` على الكمبيوتر، حدد **كل اللي جواه** (مش الفولدر نفسه) واسحبهم على الصفحة. استنى لحد ما يخلص، وبعدين **Commit changes**.
4. من **Settings** ثم **Pages**: تحت Branch اختار `main` وبعده `/ (root)` واضغط **Save**.
5. استنى دقيقة. الرابط هيظهر فوق: `https://اسمك.github.io/coin/`

## الاستخدام
1. افتح `الرابط/admin.html` في كروم. فوق رابط الشاشة، دوس "نسخ".
2. حط الرابط في تيك توك لايف استوديو.
3. افتح TikFinity وسيبه شغال.
4. دوس "تشغيل" و"اختبار التمديد".

الشاشة اللي في الاستوديو هي اللي بتعدّ وبتشغّل الوقت، ولوحة التحكم بتكلّمها عن طريق النت.
